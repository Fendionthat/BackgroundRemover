Erase paints transparent. Restore is a smart "magic wand" — touch a spot and it grows through connected, similarly-colored pixels (great for filling back a whole wall or sky in one go).

What do these mean?
Brush size
How big an area each click/drag touches. For Restore, this is the size of the starting spot — it can still grow much bigger from there.
Erase softness
How feathered the erase edge is. 0% is a hard-edged cut; higher values fade out gradually, which blends better with soft/blurry edges like hair or fur.
Restore tolerance
How different two neighboring pixels can be and still count as "the same area." Low tolerance only fills near-identical color (safer, stays inside real edges). High tolerance spreads more freely across shading and gradients, but risks leaking into the subject.
